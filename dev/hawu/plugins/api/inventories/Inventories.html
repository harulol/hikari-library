Class Inventories

  • All Implemented Interfaces:
    
public final class Inventories

    Apparently, invocations of methods relating to inventories within event handlers that handle org.bukkit.event.inventory.InventoryClickEvent are not safe, so this class provides a "safer" way of invoking said methods.

    Keep in mind that these methods are only better than its direct counterpart if these are invoked within said event handlers.

    This has no other special effect.
