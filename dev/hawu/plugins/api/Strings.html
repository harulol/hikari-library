      • fillPlaceholders

        @NotNull() static String fillPlaceholders(@NotNull() String message, @NotNull() Array<Pair<out Object, out Object>> params)

        Fills in the placeholders if present within the String with the provided pairs of parameters. Parameters should be passed in as Pair<String, Object>s, with the first value being non-null, and the second being nullable.

        For a pair with first=placeholder and second=value, all occurrences of %placeholder% with be replaced with value.

        Parameters:
        message - The message to fill.
        params - The parameters to fill with.
