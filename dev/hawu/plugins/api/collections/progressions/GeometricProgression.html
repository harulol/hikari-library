    • Method Detail

      • getTerm

         double getTerm(int n)

        Gets the term at the index n (1-indexed).

        The minimum value of this progression is considered the first term ( n = 1}).

        For example, for a geometric progression starting from 1, raising up by 5 (which is the step), we have: 1, 5, 25, 125, 625, ...

        The first term (n = 1) will be 1. The second term (n = 2) will be 5.

      • getNthTerm

         int getNthTerm(double v)

        Gets the minimum term index that has the value the closest to the provided value, but does not go over it.

        For example, for a geometric progression starting from 1, raising up by 5 (which is the step), we have: 1, 5, 25, 125, 625, ...

        By passing in, for example, a value of 126, which is greater than the 4th term, but less than the 5th term.

        This method should return 4 per specification.
