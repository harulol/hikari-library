    • Method Detail

      • getTerm

         double getTerm(int n)

        Gets the term at the index n (1-indexed).

        The minimum value of this progression is considered the first term ( n = 1}).

        For example, for an arithmetic progression starting from 1, going up by 5 (which is the step), we have: 1, 6, 11, 16, 21, ...

        The first term (n = 1) will be 1. The second term (n = 2) will be 6.

      • getNthTerm

         int getNthTerm(double v)

        Gets the minimum term index that has the value the closest to the provided value, but does not go over it.

        For example, for an arithmetic progression starting from 1, going up by 5 (which is the step), we have: 1, 6, 11, 16, 21, ...

        By passing in, for example, a value of 12, which is greater than the 3rd term, but less than the 4th term.

        This method should return 3 per specification.
