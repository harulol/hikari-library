Class DefaultHashMap

  • All Implemented Interfaces:
    java.io.Serializable , java.lang.Cloneable , java.util.Map 
    
public final class DefaultHashMap<K, V>
extends HashMap<K, V>

    Represents a mutable hash map that has a default value, and should never yield null as a result from get.
