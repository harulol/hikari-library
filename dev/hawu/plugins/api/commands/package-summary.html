Package dev.hawu.plugins.api.commands

A small module designed to work with commands registration and handling.

See: Description

  • Annotation Summary 
    Annotation Description
    CommandAnnotates a method as an invocable command.
    CommandPermissionAnnotates a method, if it is an invocable command that the sender needs permissions to run.
    TabExecuteMarks a method that provides tab completions for a command method in the same class.
  • Class Summary 
    Class Description
    CommandArgumentA wrapper class that represents the arguments that come with every command executions.
    CommandLineA class that parses a list of arguments and sorts them properly into a map of properties and list of leftover arguments.
    CommandRegistryA registry to register commands using annotations syntax.
    CommandSourceA wrapper class that wraps an instance of CommandSender to provide quick casting and sending colored messages.
    ExtendedCommandExecutorThe extended executor that provides an additional hash map for child commands in each instance.
    ExtendedTabCompleterExtended version of Bukkit Tab completers that provide a hashmap for each instance.
  • Interface Summary 
    Interface Description
    CommandRegistrableRepresents a class that can be registered with the registry using annotated methods.
  • Enum Summary 
    Enum Description
    SenderTypeRepresents possible types of command senders.
